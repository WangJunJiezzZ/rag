3. 面试前读 06、07 的**面试问答**，再照 03 里的"MCP + Agent 加演"练一遍

## 最重要的几句话

1. **检索召不回的证据，生成阶段补不回来**：所以先优化检索
2. **正确做法不是"都要，加起来"，而是先判断该问谁**：路由 > 融合
3. **只看总分会得出错误结论**：必须看分项和机制
4. **MCP 让 AI 能用上你的数据，而且只接一次，所有 AI 应用都能用**
5. **Agent 多答对 10 题，代价是 12 倍成本**：合理的做法是分流，简单题走固定流水线
6. **评测代码本身也要被评测**：判分器放水、花费上限算错、失败归因写错，都不会报错，只会让数字悄悄变好看
