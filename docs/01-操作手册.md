# 操作手册

> 这份文档假设你刚 clone 下来、什么都不知道。照着做就行。

## 一、五分钟跑起来

### 前提：只需要 Python ≥ 3.10

不需要 Docker、不需要数据库、不需要 API key。

### macOS / Linux

```bash
cd graphrag-lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py doctor          # 先跑这个
python run.py serve           # 打开浏览器
```

### Windows

```powershell
cd graphrag-lab
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py doctor
python run.py serve
```

### 端口被占用怎么办

```bash
python run.py serve -- --port 8777
```

`run.py` 后面的参数要用 `--` 隔开，否则会被 `run.py` 自己吃掉。这是唯一一个容易踩的语法坑。

## 三、命令清单

| 命令 | 作用 | 花钱？ | 耗时 |
|---|---|---|---|
| `python run.py doctor` | 环境自检 | 否 | 1 秒 |
| `python run.py phase0` | 生成语料 → 评测集 → 数据自检 | 否 | 5 秒 |
| `python run.py retrieval` | 检索评测（核心那张表） | 否 | 40 秒 |
| `python run.py build-graph` | 规则抽取知识图谱 | 否 | 2 秒 |
| `python run.py build-graph -- --extractor llm` | **LLM 抽取** | **约 ¥1.5** | 13 分钟 |
| `python run.py e2e` | 端到端评测 | 视情况 | 1 分钟 |
| `python run.py e2e -- --ab` | **三版 prompt A/B** | **约 ¥2** | 3 分钟 |
| `python run.py report` | 生成 HTML 报告 | 否 | 1 秒 |
| `python run.py serve` | Web 演示 | 提问时才花 | — |
| `python run.py all` | 除 LLM 抽取外的全流程 | 否 | 30 秒 |

**重跑同一条命令不会重复花钱**——所有 LLM 调用都按 `hash(模型+prompt+参数)` 落盘缓存，命中就直接读盘。

## 四、API key 填在哪

```bash
cp .env.example .env        # Windows: copy .env.example .env
```

编辑 `.env`，**只改一行**：

```bash
GRAPHRAG_LLM=deepseek
DEEPSEEK_API_KEY=sk-你的key       # ← 就这一行
```

填完跑 `python run.py doctor` 确认变成 `[ok]`。

`.env` 已在 `.gitignore` 里，不会被提交。

### 四种 provider

| `GRAPHRAG_LLM` | 什么时候用 |
|---|---|
| `deepseek` | 日常开发，便宜 |
| `claude` | 需要原生引用和严格 schema 时 |
| `ollama` | 本地模型，完全离线免费 |
| **`replay`** | **面试演示用这个**——只读磁盘缓存，零网络零调用 |

**没填 key 时会自动降级成 `replay`，不会报错。** 缓存里没有的问题会提示你先预跑。

## 五、面试当天怎么保证不翻车

演示前一天在有网的环境把要演示的问题**预跑一遍**，结果会进缓存：

```bash
GRAPHRAG_OFFLINE=0 python run.py e2e --ab --split train
```

**然后必跑这一步验证**（这是硬性检查，不是可选项）：

```bash
python run.py verify-replay --split train --all
```

看到 `39/39 命中  [PASS] 离线演示可用` 才算过。
**任何一题未命中，演示时那题的答案区就是空的。**

演示当天 `.env` 里 `GRAPHRAG_OFFLINE=1`，直接：

```bash
python run.py serve --port 8777
```

这样现场**零网络、零调用、每次结果完全一样**。不会出现"这次模型答得不如上次"的情况。

演示要的是可复现，不是开盲盒。

## 七、常见问题

**Q: Windows 上中文显示成乱码**
A: 先跑 `python run.py doctor`，看"中文输出测试"那行。代码已做了 UTF-8 处理，若仍乱码，改用 **Windows Terminal** 或 PowerShell 7，别用老式 `cmd.exe`。

**Q: `pip install` 卡住或报错**
A: 只有 `onnxruntime` 是必须的（向量检索）。装不上就在 `.env` 里设 `GRAPHRAG_EMBED=none`，退化成纯关键词检索，其他功能全部正常。

**Q: 服务启动很慢**
A: 首次启动要把 1092 个文本块向量化，约 60~90 秒。之后提问是毫秒级。

**Q: 换台电脑要重新下模型吗**
A: 不用。`models/` 目录已经在 git 里，clone 下来就有。

**Q: `.venv` 能拷贝到另一台电脑吗**
A: **不能。** 里面是绝对路径和平台专属的包，换机器必然报错。必须重新 `python -m venv .venv` + `pip install`。

**Q: 数据是真的吗**
A: 全部是程序生成的。公司名、人名、辖区名、风险等级都是虚构的，不涉及任何真实机构或个人。
